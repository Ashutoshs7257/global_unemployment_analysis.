# 🌍 Global Unemployment Analysis (1991–2024)

##  Project Overview

Through data cleaning, aggregation, and statistical analysis, this project highlights countries with the highest and lowest unemployment rates, compares average unemployment levels across nations, and examines global unemployment trends over time.

---

##  Objectives

* Analyze unemployment rates across multiple countries.
* Identify countries with the highest and lowest unemployment rates.
* Calculate average unemployment rates by country.
* Determine global unemployment trends over time.
* Generate meaningful insights from historical labor market data.

## Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook
* Matplotlib (optional for visualization)

---

##  Dataset

The dataset contains unemployment rate information for countries worldwide between 1991 and 2024.

Features include:

* Country Name
* Country Code
* Year
* Unemployment Rate (%)

---

##  Analysis Performed

### 1. Data Cleaning

* Handled missing values.
* Verified data types and structure.
* Prepared the dataset for analysis.

### 2. Extreme Value Analysis

* Identified the country and year with the highest unemployment rate.
* Identified the country and year with the lowest unemployment rate.

### 3. Country-Level Analysis

* Calculated average unemployment rates for each country.
* Ranked countries based on unemployment performance.

### 4. Global Trend Analysis

* Computed yearly global average unemployment rates.
* Examined long-term unemployment patterns from 1991–2024.

---

## Key Insights

* Certain countries experienced significantly higher unemployment rates due to economic and political factors.
* Several countries maintained consistently low unemployment levels throughout the observed period.
* Global unemployment trends show fluctuations associated with major economic events and global crises.
* Long-term analysis helps reveal labor market resilience and economic recovery patterns.
